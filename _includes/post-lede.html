{%- comment -%} A post's leading story headlines, for post cards. {% include post-lede.html post=post words=18 %} Sets, for the caller: lede_total how many real story headings the post has lede_1..3 the first three, truncated to `words`; for a post with no story headings, lede_1 is its opening text at 40 words Prints nothing, so the caller chooses the markup. The headlines themselves are picked once per build by _plugins/site_index.rb (AisengSite::Lede): story headings minus the one that restates the title and scaffolding such as "Top Stories". This include only truncates them. Doing the picking here, in Liquid, took 8.5 s a build. Only for posts that have already been converted: pages (homepage, series) are rendered after all posts, so they can use it. A post's own "More in" list cannot, and is filled in by the plugin instead. {%- endcomment -%} {%- assign _words = include.words | default: 20 -%} {%- assign _lede = include.post.lede -%} {%- assign lede_total = _lede.total | default: 0 -%} {%- assign lede_1 = '' -%} {%- assign lede_2 = '' -%} {%- assign lede_3 = '' -%} {%- if lede_total > 0 -%} {%- assign lede_1 = _lede.items[0] | truncatewords: _words -%} {%- if _lede.items[1] -%}{%- assign lede_2 = _lede.items[1] | truncatewords: _words -%}{%- endif -%} {%- if _lede.items[2] -%}{%- assign lede_3 = _lede.items[2] | truncatewords: _words -%}{%- endif -%} {%- elsif _lede -%} {%- assign lede_1 = _lede.fallback | truncatewords: 40 -%} {%- endif -%}
