--- layout: page title: Search description: "Search every brief and article on the site." permalink: "/search/" # A search box has no content of its own to rank. Keeping it out of the index # and the sitemap stops Google spending crawl budget on it; `follow` still # lets any links through. noindex: true sitemap: false # Short banner, so the search box is on screen without scrolling. header-style: compact # No AdSense here: Auto ads put a tall slot between the banner and the box. ads: false --- {%- comment -%} Pagefind (https://pagefind.app). The deploy workflow runs it over the built site, which writes the index to /pagefind/ in small pieces, and this page fetches only the pieces a query needs -- a few hundred KB instead of the 16 MB search-data.json that the previous Lunr search downloaded up front. What gets indexed is marked in the layouts with data-pagefind-body: post bodies, plus pages with `search: true`. Pagefind keeps one index per page language, so Chinese posts (lang zh-CN, see _plugins/site_index.rb) are in their own index; mergeIndex below searches both at once. Locally, `jekyll serve` has no index. Build, then run Pagefind: JEKYLL_ENV=production bundle exec jekyll build npx -y pagefind@1.5.2 --site _site --serve {%- endcomment -%}
